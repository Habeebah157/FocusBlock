# FocusBlock Privacy Policy

Last updated: September 17, 2026

FocusBlock helps users block distracting websites for a period of time.

## Data handling

FocusBlock stores the website domains selected by the user and their blocking expiration times locally in the browser using Chrome extension storage. FocusBlock uses website URLs during navigation to determine whether a selected website should be blocked.

FocusBlock does not send browsing data, website content, or stored blocking rules to a server. FocusBlock does not sell, share, or transfer user data to third parties.

## Data collected

FocusBlock does not collect personally identifiable information, health information, financial information, authentication information, personal communications, location data, website content, or user activity such as clicks or keystrokes.

Website addresses are used only for the extension's single purpose: blocking websites selected by the user. Blocking rules remain stored locally in the user's browser.

## Changes to this policy

If the extension's data practices change, this policy will be updated before those changes take effect.

## Contact

For privacy questions, contact the extension publisher through the contact information on the Chrome Web Store listing.
